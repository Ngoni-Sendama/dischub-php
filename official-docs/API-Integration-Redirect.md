# API Integration Redirect

Dischub provides a straightforward integration for accepting payments between Dischub and a merchant's online platform. This guide explains how to:

- create a new payment order
- complete a payment from the Dischub platform
- receive payment status updates

If you have no programming experience, you can work with a developer to set up this integration.

This integration supports test-environment simulation.

## 1. Configure Your Account

Before integrating, configure your Dischub account.

1. Visit the Finance page to manage settlement bank accounts and wallets under `Gateway > Finance`.
2. Visit `Gateway > Configurations`.
3. Generate an API key by clicking the **Generate** button.
4. Enter your business name as it should appear to clients during payment.
5. Attach your business logo.
6. Add your website URL if applicable.

## 2. Create an Order or Initiate Payment

To create a payment order, send a `POST` request to the Dischub order-creation endpoint. The request must include the endpoint URL, headers, and payload.

### Endpoint

```text
https://dischub.co.zw/api/orders/create/
```

### Request Headers

The API uses `application/json`. Your API key must be included in the headers, not in the request body.

```json
{
  "Content-Type": "application/json",
  "X-Api-Key": "6945f57cdbf14b00812cb15df1933f2a"
}
```

### Request Data

Replace the values below with your own payment details:

```json
{
  "order_id": "344245663",
  "sender": "+263780070488",
  "recipient": "softwarez@gmail.com",
  "amount": 14.58,
  "currency": "USD",
  "callback_url": "https://softwarez.co.zw/payment/status/",
  "redirect_url": "https://softwarez.co.zw/take/me/back/",
  "mode": "test"
}
```

### Required Fields

- `order_id`: A unique string used to track the transaction. It must be a string, unique across all orders, and no longer than 30 characters.
- `sender`: The customer's phone number. Accepted formats include `+263780070488`, `0263780070488`, and `0780070488`.
- `recipient`: The email address used to create the Dischub merchant account.
- `amount`: The payment amount. Must be a valid number greater than `0` and less than `100000`.
- `currency`: Supported values are `USD` and `ZWG`.
- `callback_url`: Optional. The URL Dischub will call with a payment status once the transaction is processed. Must use the `https` scheme.
- `redirect_url`: Optional. The URL the customer is redirected to after completing the payment. Must use `http` or `https`.
- `mode`: Use `test` for the testing environment and `live` for the production environment.

## 3. Redirecting to Dischub

This step occurs only after you receive a successful response from step 2. If the response is not successful, fix the integration before continuing.

After a successful order creation, the user is redirected to:

```text
https://dischub.co.zw/api/make/payment/to/{order_id}
```

Where:

- `{order_id}` is the unique order ID generated by your system for the transaction.

Example:

```text
https://dischub.co.zw/api/make/payment/to/344245663
```

## 4. Completing Payment

Once the customer is redirected to the Dischub platform, they choose a payment method and complete the payment process until they receive either a **Payment successful** or **Payment failed** result.

## 5. Receiving Payment Status

This applies when the `callback_url` is not receiving payment status updates from Dischub or when no `callback_url` is set because it is optional.

After payment processing, make a `POST` request to the Dischub payment status endpoint to track transaction success or failure in real time.

### Steps to Handle Payment Status

1. Make a `POST` request to the Dischub payment status endpoint with the appropriate arguments.
2. Receive the payment status as a JSON payload.
3. Update your database or application using the returned data.

### Endpoint

```text
https://dischub.co.zw/api/payment/status/3/step/
```

### Request Headers

```json
{
  "Content-Type": "application/json",
  "X-Api-Key": "6945f57cdbf14b00812cb15df1933f2a"
}
```

### Request Data

Replace the values with your own credentials and the order you want to check:

```json
{
  "order_id": "344245663",
  "recipient": "softwarez@gmail.com"
}
```

### Required Fields

- `order_id`: The same order ID used when creating the order in step 2.
- `recipient`: The email address used to create the Dischub merchant account.

### Responses

#### Successful Response

```json
{
  "order_id": "344245663",
  "recipient": "Your Business Name",
  "sender": "+263780070488",
  "status": "success",
  "status_reason": "Reason...",
  "currency": "USD",
  "amount": "14.58",
  "timestamp": "2025-01-09 04:20:08.702591+00:00"
}
```

#### Error Responses

```json
{
  "status": "error",
  "message": "missing api key in request headers",
  "response_code": 401
}
```

```json
{
  "status": "error",
  "message": "missing or invalid required keys in request data",
  "response_code": 422
}
```

```json
{
  "status": "error",
  "message": "authorization failed: wrong api key or recipient identifier",
  "response_code": 401
}
```

```json
{
  "status": "error",
  "message": "no order found matching the provided order_id and recipient",
  "response_code": 404
}
```

```json
{
  "status": "error",
  "message": "an unexpected error occurred while retrieving the order",
  "response_code": 500
}
```

The `status` field in a successful response can contain the following values:

- `success` — payment completed.
- `pending` — payment not yet confirmed.
- `failed` — payment failed or timed out.

Use this information to update your system or database accordingly.
